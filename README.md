# 简介

本项目生成适用于 [**Quantumult X**](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://apps.apple.com/us/app/quantumult-x/id1443988620&ved=2ahUKEwihwPjMrumQAxUuLUQIHY_jJkEQFnoECB4QAQ&usg=AOvVaw1q88XwHgp0rY-Lh4TBn9kV) 的规则集（RULE-SET）。

## 说明

本项目规则集（RULE-SET）的数据主要来源于项目 [@Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat) 和 [@v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)；[`Apple`](https://github.com/Lonense/quanx-rules/blob/release/apple.txt) 和 [`Google`](https://github.com/Lonense/quanx-rules/blob/release/google.txt) 列表里的部分域名来源于项目 [@felixonmars/dnsmasq-china-list](https://github.com/felixonmars/dnsmasq-china-list)；中国大陆 IPv4 地址数据使用 [@17mon/china_ip_list](https://github.com/17mon/china_ip_list)。
